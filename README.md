# easytalk

Личная клавиатура для iPhone для тех, кто пишет по-английски с русскими вставками.

- **Пишешь как обычно** в Telegram, WhatsApp, почте — клавиатурой easytalk.
- **История вводов** собирается сама: отправленное сообщение сохраняется на телефоне (90 дней).
- **«Скопировать контекст»** — задание и твои сообщения за период (30 минут … всё время) в буфер. Вставляешь в любой ИИ (Claude, ChatGPT…) — он разбирает типичные ошибки и даёт упражнения.
- **«Вставить слова»** — слова из ответа ИИ попадают в словарь, карточки и игру.
- **«Перевести»** (необязательно) — мгновенный перевод и разбор в поле через свой ключ: OpenAI, Claude, Qwen или DeepSeek.
- Диктовка — системной кнопкой 🎙 iOS.

Mac-приложение (плавающая панель) существует, но сейчас на паузе.

## Сборка и установка

Mac не нужен: всё собирается в GitHub Actions.

- Каждый push и PR — тесты, Mac-сборка, iOS-сборка без подписи.
- Установка на iPhone — через TestFlight: Actions → TestFlight → Run workflow.

Подробно — [docs/CI.md](docs/CI.md).

| `docs/` | Архитектура, решения, план, CI; `docs/history/` — история до 12.10.2026 |
