# Решения

Действующие решения автора и причины. Новое решение — новая строка вверху раздела; отменённое не удалять, а зачёркивать со ссылкой на замену. История до 12.10.2026 — `docs/history/`.

## Продукт

| Дата | Решение | Почему |
|---|---|---|
| 2026-10-14 | Настройки — один список разделов; подключение AI — пошаговый мастер (провайдер → где взять ключ → вставить → автопроверка), затем карточка: Проверить / Модель / Сменить / Удалить. Регион, адрес и рабочее пространство — только у провайдеров, которым они нужны; для AWS — регион вместо адреса | Прежний экран был громоздким, новичку было непонятно, где взять ключ и что вводить |
| 2026-10-14 | «Перевести» без выделения берёт всё сообщение; настройка «Сообщение / Абзац / Предложение»; выделение переводится как есть | Обычно переводят всё набранное сообщение, а не последнюю строку |
| 2026-10-14 | «В словарь» для выделенного слова или фразы: сохраняется сразу; с ключом AI добавляет перевод и примеры, без ключа слово ждёт «без перевода» — его переводит внешний ИИ через «Скопировать контекст» → «Вставить слова» | Словарь пополняется и без ключа; слова без перевода не попадают в игру |
| 2026-10-14 | Подсказки слов по умолчанию выключены, ряд виден только когда есть подсказки; советы о клавиатуре — по одному при появлении, не чаще раза в 30 минут, отключаются | Ряд занимал место; новые возможности нужно показать, не мешая набору |
| 2026-10-12 | Главное — автоматическая история вводов и «Скопировать контекст» в любой ИИ; импорт слов из ответа ИИ | Разбор за период видит повторяющиеся ошибки; диалог с ИИ удобнее в его собственном чате, чем на экране клавиатуры |
| 2026-10-12 | Перевод в поле — по своему ключу: OpenAI, Claude, Qwen, DeepSeek; без ключа приложение работает полностью | Каждый выбирает свой ИИ; без сервера и общих расходов |
| 2026-10-12 | Свой сервер (`/v1/ai`) удалён | Нигде не развёрнут, усложнял код |
| 2026-10-12 | История пишется только автоматически (опустевшее поле), 90 дней | Без лишних нажатий; тексты, где поле не очищается (заметки, почта), могут не попасть — принято |
| 2026-10-12 | Периоды копирования: 30 минут, час, сегодня, неделя, всё время | — |
| 2026-10-12 | Словарь, карточки и игра остаются; словарь до 1000 слов | Импорт списками быстро вытеснял слова при старом пределе 200 |
| 2026-10-12 | Mac — на паузе | Сначала довести iPhone |
| 2026-10-12 | Лаборатория произношения заморожена, ONNX Runtime убран; код в теге `v0.5.0-build26` | Не используется, 109 МБ |
| 2026-10-08 | Диктовка — только системная кнопка 🎙 iOS | Клавиатура не может писать микрофон; все обходы (переход в приложение, свой микрофон, приватные API) отвергнуты. Смешанная EN+RU диктовка не решена |
| до 10-12 | Пол говорящего — только в настройках; «В словарь →» рядом с правкой, без ×; вторичные действия — единый пунктир; «Запомнил» архивирует слово | Решения по интерфейсу 0.3.x–0.4.x (`docs/history/LINKS_038.md`, `UX_040.md`, `KEYBOARD_042.md`) |

## Техника

| Дата | Решение | Почему |
|---|---|---|
| 2026-10-15 | Перед «Перевести» без выделения клавиатура читает поле целиком: курсор идёт в конец и обратно к началу, текст собирается по кускам, курсор возвращается. Если поле длиннее 12 000 знаков, не отвечает или курсор вернулся не туда — переводится видимый кусок | iOS отдаёт `documentContextBeforeInput` урезанным, в Telegram — до предложения или запятой; так переводилась только часть сообщения |
| 2026-10-13 | Провайдер «Claude AWS» (Claude Platform on AWS): `aws-external-anthropic.{регион}.api.aws/v1`, постоянный ключ из консоли AWS в `x-api-key`, обязательный `anthropic-workspace-id`; схема ответа, запасная модель и список моделей — как у Claude API. Временные ключи (≤12 ч) распознаются, показывается срок | Автор пользуется Claude Platform on AWS; для телефона нужен постоянный ключ |
| 2026-10-13 | Claude через AWS — провайдер «Bedrock»: Messages API `bedrock-mantle.{регион}.api.aws/anthropic/v1`, ключ API Bedrock в `x-api-key`, модели `anthropic.claude-…`; без строгой схемы, списка моделей и запасной модели | Так Bedrock работает с обычным ключом без подписи SigV4; этих функций на Bedrock нет. Claude Platform on AWS не подключён: его ключи живут не больше 12 часов |
| 2026-10-12 | Claude: `claude-opus-5-5`, effort `low`, `fallbacks: "default"` | Перевод фразы — короткая задача; низкое усилие держит ответ в пределах 30 с; запасная модель при отказе |
| 2026-10-12 | Ключ API — в общем Keychain App Group, не через буфер обмена | Буфер читают другие приложения; импорт из буфера позволял подменить сервер |
| 2026-10-12 | App Groups разрешены (bundle ID `com.arsi945.easytalk`) | Есть платный аккаунт; прежний запрет был из-за бесплатной Personal Team |
| 2026-10-12 | Сборка — GitHub Actions на `macos-26` (Xcode 26); установка — TestFlight | Автор на Windows без Mac; App Store Connect принимает только iOS 26 SDK |
| 2026-10-11 | Git и PR вместо tar-архивов | История, ревью, откат |
| 2026-10-11 | Xcode-проект генерируется `ios/generate_project.py` (работает и на Windows), CI сверяет | Один источник правды для файлов целей |
