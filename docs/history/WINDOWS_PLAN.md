# Подготовка следующего desktop этапа: Windows

2026-10-06. Windows-сборка пока не создана; цель этого этапа была Mac-прототип. Общую продуктовую логику описывает ARCHITECTURE.md, взаимодействие нового окна — MACOS.md.

Можно использовать без переписывания данных: glossary/idioms-en-ru.json, prompts/analyze_translate.md, schema analyze_translate и fixtures/проверки в Core/ios/worker. Исторический веб-прототип и JS CorrectionSession полезны для проверки переноса, но мобильный UI web/index.html не равен новой Mac-версии.

Минимальный Windows план:

1. Обычный native editor с выделением, undo и Enter/newline. Те же шесть разделов, тёплые карточки, стрелка сохранения, крестик отказа, click flip и горизонтальное листание.
2. Адаптер выделение/абзац → UTF16/scalar, запрет замены изменённого документа. Перенести проверки DraftScope и cancel-generation из DesktopQA, а не просто копировать UI.
3. Личный ключ в Windows Credential Manager; локальное хранилище уроков/слов; явный JSON-экспорт. Ключ не хранить в frontend localStorage.
4. Кнопка вставки в явно выбранную прежнюю цель; проверка foreground process перед вводом. Fallback через буфер. Не читать чужой текст автоматически.
5. Выбрать desktop оболочку после проверки имеющегося окружения. Electron/Tauri/native .NET — открытое решение; не выдавать выбранный на Mac AppKit за переносимый Windows UI.
6. Синхронизация личных слов/прогресса — отдельная задача с общей версией формата и тестами миграции. Встроенная коллекция уже едина для iOS/Mac и доступна как JSON для Windows.

До публичного выпуска: подпись установщика, обновления и доступность интерфейса. Детальные вопросы автора перенесены на его возвращение.
