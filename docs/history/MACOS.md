# easytalk для macOS · прототип 0.3.3

Плавающая панель справа с нативным редактором и SwiftUI, режимами «Ввод», «Разбор», «Игра», «Словарь» и настройками. Кнопка у шестерни сворачивает её в быстрый ввод сверху справа. Минимальная система — macOS 12, проверка сборки на Intel Mac с macOS 14.8.7. Главные входы: `DesktopWindowController`, `DesktopRoot`, `DesktopModel`.

## Использование

1. Обновлён до 0.3.3 в `/Applications/easytalk.app`. Выйти ⌘Q и снова запустить приложение, чтобы применить обновление. В дальнейшем запускать из «Программы».
2. Личный ключ уже перенесён в Mac Keychain по просьбе автора. В настройках поле заполнено и скрыто; глаз показывает ключ, ← возвращает в приложение. При новом подключении указать личный ключ OpenAI. На телефоне ключ остаётся отдельно, приложение Mac его не извлекает. Оставить поле ключа пустым при последующем сохранении можно: прежний ключ сохранится.
3. Написать фразу в редакторе, поставить курсор в абзац либо выделить текст, нажать «Перевести» или ⌘Enter.
4. Русский перевод появится на месте выбранного фрагмента. ⌘Z отменяет изменение через нативный NSTextView. Enter — новая строка, Escape — отмена запроса.
5. После перевода автоматически открываются правки в «Учёбе»; сохранять слова «В словарь →» у соответствующей правки. Перефразирование и динамик — у правильной фразы. Список «Разборы занятий · N» доступен до перезапуска; на диске остаётся последний.
6. В «Идиомах» искать по слову/переводу или теме; → добавляет выражение в личный словарь. Сохраняется максимум 200 личных слов. Экспорт словаря JSON — в «Моём словаре».
7. Карточка переворачивается кликом, перелистывается горизонтальным движением мыши/трекпада. Пробел и ←/→ также работают в разделе игры. «Запомнил/Запомнила» переносит карточку в «Выучил» с коротким поощрением. В словаре вкладки «Все / В игре / Выучил»; ссылка «Вернуть в карточки» доступна у выученного слова.

Хоткей ⌃⌥Пробел вызывает окно из другого приложения. «Вставить в предыдущее приложение» использует эту явно захваченную цель и проверяет её перед отправкой ⌘V. Без разрешения Accessibility текст остаётся в буфере. Выдать доступ можно отдельным пунктом меню-бар приложения; запрос разрешения не показывается автоматически при старте. Обычная кнопка «Скопировать» не требует Accessibility.

Выделение из другого приложения: ПКМ → Службы → Отправить в easytalk, затем кнопка «Перевести» в панели. Если host не поддерживает Services, скопировать выделение и нажать «Из буфера». Автоматического дублирования всех нажатий нет. Подробности текущей версии/проверок: [MACOS_032.md](MACOS_032.md).

## Сборка

```sh
bash scripts/build.sh all
build/selftest
python3 scripts/generate_idioms.py --check
build/easytalk.app/Contents/MacOS/easytalk --desktop-check build/mac-preview
```

При полном Xcode на этой машине можно добавить перед командой `env DEVELOPER_DIR=~/Downloads/Xcode.app/Contents/Developer`. Скрипт использует локальный module cache и обход дублированного SwiftBridging в старом CLT без изменения системы. Подпись по умолчанию ad-hoc; стабильную Apple Development identity передавать через `EASYTALK_SIGN_ID`. Подпись/нотариализация для широкого распространения не подготовлены.

SwiftPM: `Package.swift` включает Core, общий модуль Learning и исполняемый EasyTalk. `--snapshot` сохранён для старого correction-panel; он не проверяет новый интерфейс.

## Проверки и ограничения

`--desktop-check` запускается до реальных сервисов, использует отдельный UserDefaults suite, память вместо Keychain, фиктивные ответы вместо сети. Проверяет область перевода, защищённую замену текста, отмену/ошибки, словарь, экспорт, прогресс игры, настройки и offscreen PNG всех основных разделов. Он не открывает рабочее окно, не читает реальный ключ, не трогает буфер и телефон.

Реальный запрос AI, пользовательский ввод/undo, глобальный хоткей, вставка в Telegram/Notes, взаимодействие с Accessibility и анимация карточки при живом клике требуют ручной проверки после возвращения автора. Число локальных успешных тестов не доказывает качество перевода. Снимки — визуальная проверка раскладки, а не автоматическая проверка всех жестов.

Нет пока: синхронизации слов/прогресса с iPhone, импорта словаря, интервального расписания, автозахвата чужого поля, настройки хоткея, Windows-сборки. Для Windows пригодится общий контракт, коллекция и логика обучения, но AppKit/SwiftUI UI и автоматическую вставку нужно реализовать отдельно.
