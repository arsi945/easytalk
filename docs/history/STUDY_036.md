# Учёба и карточки · iOS 0.3.6 / macOS 0.2.1

2026-10-06. Изменения по просьбе автора, включая подготовленные изменения 0.3.5. iOS 0.3.6 / build 6 установлена поверх существующей программы на iPhone 12 Pro Max и запущена через devicectl. Словарь, контейнер и Keychain не сбрасывались. Mac-прототип обновлён, но рабочее окно на экране автора не открывалось.

## Поведение

- В «Разборе» слова находятся у соответствующих правок с действием «В словарь →». Крестика отказа и отдельного блока предложений больше нет. Если слово не соответствует конкретной правке, оно появляется в конце после тонкой линии. Ничего не сохраняется без нажатия. Раздел уже сохранённого словаря остаётся.
- У правильной английской фразы есть «Перефразировать». AI получает именно её; исходная правильная фраза остаётся. Варианты с русскими названиями стиля и кратким пояснением сохраняются в том же уроке. Это вариативность, а не новая оценка ошибок.
- Значок динамика произносит английскую фразу, слово или вариант через AVSpeechSynthesizer и доступный системный английский голос. Не используется AI speech API и не записывается звук. У клавиатуры iOS нужен «Полный доступ». При закрытии клавиатуры/смене панели речь останавливается. Доступность и качество конкретного голоса зависят от установленных голосов системы.
- Карточка переворачивается тапом. Нативный UIScrollView с isPagingEnabled, isDirectionalLockEnabled и fast deceleration листает горизонтально вслед за пальцем. На обороте можно прокручивать длинное содержимое вертикально. Нет множителя движения 0.55, ручного порога 45 pt и fade-out/slide-in старого свайпа. Кнопки не вызывают переворот.
- Оборот: крупный русский смысл (28 pt на iPhone), меньший английский оригинал, тонкая линия, примеры, небольшой отступ, «Запомнил/Запомнила». Отметка выученного не меняется от просмотра или свайпа. VoiceOver может отдельно перевернуть/перелистнуть.
- Встроенные 60 идиом теперь имеют по два разных примера. Старые ID сохранены. Новые вторые примеры написаны для проекта, не скопированы из источников.

## Словарная форма и совместимость

`VocabularySuggestion.term` остаётся выражением, реально встретившимся в исправленной фразе: это нужно для проверки разбора. Новый `dictionary` хранит независимые `headword`, `meanings`, `examples`. Headword — английская словарная форма, смыслы на русском — существительное в именительном, прилагательное в мужском единственном, глагол в инфинитиве. Не надо выдумывать несколько значений, если у выражения одно обычное значение.

В новом strict JSON Schema профиль обязателен для каждой подсказки. Swift Codable сохраняет его необязательным для чтения старых ответов, уроков и слов. Проверяются непустая английская форма, 1–4 разных значения и 2–3 разных английских примера с ограничением длины. Это проверка формы ответа; семантическую точность AI она математически не гарантирует.

Старые личные записи не удаляются и не угадываются по русским окончаниям. Для successful подготовлено проверенное базовое значение «успешный; удачный; результативный» и три собственных примера; для известных встроенных идиом используется общий каталог. Остальные старые слова помечены «Перевод из твоей фразы»: кнопка «Уточнить значение» делает отдельный AI-запрос. Сохраняется UUID слова, позиция карточки и её прогресс. Смысл в исходной фразе остаётся в контексте урока.

## Дополнительные AI-запросы

Общий генератор: `prompts/study_actions.md` → `ios/Shared/StudyActionsPrompt.swift` и `worker/src/prompts.js`. Код: `StudyActionService.swift`, `StudyActionOperation`, Core/StudyContent.swift. Основной промпт анализа расширен в `prompts/analyze_translate.md`.

Для перефразирования user message — JSON:

```json
{"op":"rephrase","schema_version":1,"text":"исправленная английская фраза","native_language":"ru","target_language":"en"}
```

Для уточнения старого слова тот же объект с `op: "dictionary"` и `text: "слово или выражение"`. Никакие другие абзацы, весь файл или история в дополнительный запрос не включаются. Developer message — точный текст `prompts/study_actions.md`. Прямой запрос: тот же личный ключ/endpoint/model из ConnectionSettings, `max_completion_tokens: 2400`; для gpt-6-luna `reasoning_effort: none`, strict JSON Schema. Перефразирование ожидает 2–4 разных непустых варианта (промпт просит 3); словарь — один профиль. Исходный английский не заменяется вариантом автоматически. Варианты не отправляются в чужое поле.

Одна операция, общий таймаут 30 секунд, отмена и игнорирование позднего ответа. Нет повторной скрытой отправки. Переключение урока/панели или закрытие клавиатуры отменяет операцию. Прямой endpoint ограничен api.openai.com. Worker и Python имеют соответствующие операции с проверкой контрактов; внешние серверы в этом этапе не развёртывались. Работа через старый сервер потребует его обновления.
