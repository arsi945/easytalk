# Панель Mac и уточнение смысла · 2026-10-06

Актуально: iOS **0.3.9 / build 9**, macOS **0.3.0 / build 6**. Эти решения заменяют старую постоянную историю и широкое окно Mac. Функции словаря, карточек, пунктирных ссылок и 60 идиом сохранены.

## Mac

Плавающая NSPanel справа: ширина по умолчанию 392 pt, отступ 12 pt от правого и верхнего края доступной области экрана. Развёрнута почти на высоту экрана, максимум 900 pt. Кнопка со сходящимися стрелками сворачивает её в плашку 260 pt высотой с нативным полем быстрого ввода; противоположная раскрывает. Панель остаётся видимой при переключении приложений. Настройки компактности и собственный черновик сохраняются в UserDefaults.

Ввод через обычный NSTextView и штатную клавиатуру. Нет наблюдения за всеми нажатиями или автоматического чтения чужих текстовых полей. Выделить фрагмент в другом приложении → ПКМ → «Службы» → «Отправить в easytalk». macOS передаёт только выделение через специальный pasteboard; служба выбирает весь импортированный фрагмент в нашем редакторе. Передача сама не вызывает AI: пользователь нажимает «Перевести». Обычный хоткей ⌃⌥Пробел открывает панель, без чтения чужого текста. Запасной вариант: скопировать выделение, открыть панель, нажать «Из буфера».

Пункт службы зависит от поддержки Services в исходном приложении. Если он выключен, проверить Системные настройки → Клавиатура → Сочетания клавиш → Службы. Зарегистрирован `NSServices`, send-only, UTF8 plain text и legacy NSStringPboardType; `lsregister -f` вызван для установленного bundle. Глобальный сброс LaunchServices не выполнялся. Основа: [Apple NSServices](https://developer.apple.com/documentation/bundleresources/information-property-list/nsservices). Живой пункт контекстного меню в Notes/Telegram ещё требует ручной проверки после перезапуска установленного приложения.

Перевод получает выделение или текущий абзац собственного редактора. На пустой строке в конце после Enter берётся последний непустой абзац; позиции и переносы сохраняются, целый документ автоматически не отправляется. Пустое поле показывает подсказку; отсутствие ключа открывает настройки. Кнопка становится «Отменить» во время запроса. Редактирование/смена курсора отменяет запрос с объяснением; поздний ответ не заменяет новый текст. Таймаут/HTTP/невалидный ответ видимы, оригинал сохраняется. Повторный перевод неизменённого результата приглушён.

Пользователь сообщил «нажатие — ничего не происходит». Проверены и исправлены условия, создававшие неясное поведение, но точная причина в его старом открытом экземпляре не подтверждена. Нативный QA проверяет delegate редактора, вызов настоящего AnalysisOperation через изолированный URLSession/URLProtocol, немедленный прогресс, один mock-запрос, видимую HTTP503 и неизменный черновик. Настоящий ключ не читался для отладки, живой OpenAI-запрос не выполнялся.

Установлено `/Applications/easytalk.app` 0.3.0 / 6. Открытый старый процесс не прерывался: требуется именно выход ⌘Q и повторный запуск; простое закрытие окна оставляет прежний процесс. Прежний bundle сохранён в `archive/installed-mac/20261006-before-030/easytalk.app`. Проверен ZIP `archive/releases/easytalk-macos-0.3.0-intel.zip`, SHA256 рядом, исполняемый файл совпадает с установленным.

## Уточнение смысла на iPhone

После перевода исправить русский текст в родительском приложении. Вернуться к easytalk через системный 🌐, открыть последний разбор стрелкой у «Перевести», нажать пунктирную ссылку «Уточнить смысл по русскому тексту». Курсор должен быть в конце нужного абзаца или фрагмент явно выделен. Keyboard extension видит только доступный контекст/выделение, не весь файл. Максимум 2000 Unicode scalars; требуется русская буква, подключение AI, Full Access.

Второй запрос содержит оригинальный английский/смешанный ввод и новый русский смысл:

```json
{"op":"revise_analysis","schema_version":1,"text":"I like coffee","intended_meaning":"Я предпочитаю чай","native_language":"ru","target_language":"en","context":"casual_chat"}
```

`speaker_gender` добавляется только если указан в настройках. В direct API это JSON внутри user message обычного Chat Completions envelope; developer prompt — общий analyze_translate с дополнением о приоритете намерения. Формат ответа, strict schema, лимит, 30-секундный deadline и одна попытка исправления несогласованного ответа прежние. При repair уточнение также сохраняется в user message. Python/Worker понимают новую op; rules возвращает 501 вместо выдуманного анализа.

AI заново строит естественный английский, правки относительно оригинала, пояснения и слова. Разница только из-за уточнённого смысла имеет тип style, настоящая грамматическая ошибка — error. Урок сохраняет тот же UUID и исходник, русский смысл записывается точно из поля, прежние варианты перефразирования сбрасываются. Новые варианты можно запросить отдельно. Русский текст в родительском поле при уточнении не вставляется и не удаляется. Поощрения не начисляются повторно. Словарь остаётся неизменным, новые предложения можно сохранить явно.

Уточнение доступно для последнего перевода. Совпадение snapshot/идентификатора документа/UUID урока защищает от позднего ответа после изменения текста, поля или перевода. Сбой/отмена сохраняет старый разбор. После пересоздания extension известный идентификатор поля может отсутствовать: действие всё равно явно берёт текущий русский фрагмент, не записывает в чужое поле. Система не умеет определить намерение без предоставленного пользователем смысла.

## Занятие вместо постоянной истории

Все успешные разборы текущего процесса доступны в раскрываемом списке «Разборы занятия · N». Без «Новее/Раньше», без счётчика перелистывания. Выбранный старый разбор можно читать, перефразировать и сохранять его слова. Уточнить смысл — только у последнего. Список в памяти, не дописывается на диск. Сохраняется один последний разбор для возвращения после перезапуска; старые сохранённые массивы мигрируют к одной записи. Личный словарь и прогресс игры сохраняются полностью в пределах прежнего лимита 200 личных слов.

Занятие здесь — время жизни процесса приложения/extension, не каждая смена клавиатуры глобусом. iOS может выгрузить extension: тогда список занятия сбросится до последнего разбора. Это ограничение явно принято вместо годовой базы на 10000 фраз. В настройках клавиатуры есть «Завершить занятие и сбросить разборы»: pending запрос отменяется по generation, поздний ответ не возвращает уроки; словарь не удаляется.
