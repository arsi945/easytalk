## Основной цикл iPhone

В обычном вводе справа у ⚙ одна компактная кремовая группа «Перевести ↓». Название пока короткое предварительное. Нажатие текста запускает перевод доступного абзаца/выделения. Стрелка открывает последний разбор без нового AI-запроса. Отдельной кнопки «Учёба» нет.

После запуска перевода строка меняется на «Разбор · Игра · Словарь · ⚙». В «Разборе» видны ожидание/отмена или ошибка/повтор, после успеха — правки. Ошибка не блокирует переход в «Игру» или «Словарь». Это не дополнительное поле ввода: русский перевод заменяет соответствующий фрагмент поля приложения. Небольшая ссылка «К вводу ↓» возвращает буквы. Через системный 🌐 по-прежнему можно сменить клавиатуру; дополнительной кнопки клавиатуры нет.

«Перефразировать в разных стилях» — текстовая ссылка внутри карточки правильной английской фразы. Варианты сохраняются в том же уроке и раскрываются внутри этой карточки. «Свернуть варианты ↑», «Показать варианты · N ↓» и нижнее «К замечаниям · свернуть варианты ↑» меняют только отображение, не вызывают AI. Исправленная фраза, правки и предложения слов сохраняются. Переход к другому разбору/разделу отменяет незавершённое учебное действие; поздний ответ не применяется.

Каждое предлагаемое слово имеет свою ссылку «В словарь →» и увеличенный вертикальный отступ. Слова у правок остаются внутри соответствующей правки. Оставшиеся слова идут в конце с тонкой линией; отдельных кнопок × нет.

## Архив и карточки

Игра открывается сразу на первой карточке. Tap — flip, native UIScrollView paging — swipe, вертикальный скролл на длинном обороте. Карточка не становится выученной от просмотра, flip или swipe.

«Запомнил/Запомнила» удаляет текущую карточку только из массива текущего раунда и отмечает её ID выученным. Следующая карточка показывается английской стороной; возврат свайпом не возвращает выученную карточку. Короткое «🌟 +1 выученное слово» сопровождает уход карточки. При выключенных поощрениях остаётся нейтральное «Слово в „Выучил“»; Reduce Motion убирает уход-анимацию. Последняя карточка ведёт к завершению раунда с числом выученных слов. Для этой логики `StudySession.initialCount` сохраняется даже при пустом массиве; `rememberedCount` считает и убранные карточки.

Словарь: «Все · В игре · Выучил». У активной записи справа внизу «Выучил», у выученной «Вернуть в карточки». Выученное слово не удаляется из личного словаря. «Подробней о слове» — вторичная текстовая ссылка на AI-уточнение, а не большая кнопка. Удаление личного слова доступно в раскрытых подробностях на iPhone / меню ⋯ на Mac.

Личные слова видны всегда. Встроенная идиома попадает в этот словарь только после явной отметки «Запомнил»: каталог всех 60 не добавляется в личный список сам. `practice.introduced` помнит такую идиому после её возврата в игру; существующие `practice.learned` ID учитываются для совместимости. Идиома, уже сохранённая как личное слово, дедуплицируется по термину в игровом пуле. UUID слов, lesson ID и старые стабильные ID идиом сохраняются.

## Старое benefit

Для `benefit` добавлена узкая офлайн-запись: «польза; выгода», «льгота; пособие», «приносить пользу; получать пользу» и три своих примера. Источник основных значений — [Cambridge Dictionary](https://dictionary.cambridge.org/dictionary/english/benefit). Она используется для старого contextual-перевода без dictionary metadata и для обнаруженной ошибочной metadata с единственным значением «пользу». Другие существующие корректные профили не заменяются. UUID и состояние выученности сохраняются; нажатое ранее «Запомнил» означает перенос в «Выучил».

Новые AI-промпты уточняют каноническую форму benefit/successful. Это не алгоритм отрезания русских окончаний. Для прочих старых неизвестных слов нужна явная ссылка «Подробней о слове»; обещать автоматическое исправление всех старых слов нельзя. AI-транспорт, модель, лимиты и схема запросов сохраняются из STUDY_036.md.
