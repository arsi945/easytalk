# Ссылки, словарь и настройки · 2026-10-06

Актуально: iPhone **0.4.0 / build 10**, Mac **0.3.1 / build 7**. Установлены обе сборки. Это уточнение к PANEL_MEANING_039.md, правила хранения занятия/словаря и протокол AI не изменились.

## Уточнение только после правки

iOS показывает «Уточнить смысл по русскому переводу» только у последнего разбора, когда доступный русский текст отличается от сохранённого перевода. Пробелы по краям игнорируются. Возврат прежнего текста и успешное уточнение скрывают ссылку. При известном document ID другой документ её не получает. Исторический разбор не предлагает уточнять текущий текст другого сообщения.

Для чтения смысла, в отличие от обычной замены при переводе, курсор может быть внутри абзаца. `currentRussianText` соединяет доступный хвост перед курсором, выделение и доступное начало после курсора до границы абзаца. Выделить неизменённое слово — не изменение: полная фраза восстанавливается с обеих сторон. Многоабзацный перевод нужно выделить целиком. Разбор обновляется по оригинальному английскому и новому русскому смыслу, без вставки/удаления в родительском приложении.

Ограничение keyboard extension остаётся: весь файл и текст за пределами `textDocumentProxy` не доступны. Ссылка оценивает доступный фрагмент; скрытый/усечённый контекст приложения может ограничить определение изменения. После пересоздания extension старый ID поля может отсутствовать, тогда сравнивается текущий русский текст с последним сохранённым переводом. Не обещать полноценный доступ к документу или общий перехват ввода.

## Перевод и исходник

Названа ссылка «Разборы занятий · N» на обеих платформах. У каждой английской фразы в раскрытом списке есть «Перевод ↓» с отдельным состоянием по UUID; раскрытие не выбирает другой урок, не пишет в текущее сообщение и не вызывает AI. Эта же маленькая пунктирная ссылка доступна под английским текстом в основной карточке разбора. Исходный текст с подсветкой раскрывается сразу после «Исходный текст ↓», до последующих ссылок и вариантов. Mac исходник также скрыт под своей ссылкой, появляется непосредственно под ней.

## Словарь

iOS: шеврон раскрытия 12 pt без фона/рамки, вверху справа. Невидимая зона касания 44×44 pt сохранена. Динамик находится сразу после английского термина, русский смысл ниже. Примеры и словарные подробности раскрываются прежним действием. Mac личный словарь использует аналогичный маленький plain шеврон и динамик рядом с термином; примеры по умолчанию свёрнуты. Глобус, мастерство, фильтры, словарные значения и карточки не изменены.

## Mac настройки и стандартная строка окна

Стрелка ← вверху слева возвращает на прежнюю страницу и восстанавливает компактный ввод, если настройки открыты оттуда. Сохранение/отключение подключения не лишает пользователя возврата. Панель сохраняет положение справа, но styleMask теперь titled/closable/miniaturizable/resizable, без utilityWindow: системная строка и стандартные элементы окна вместо уменьшенной служебной полосы.

В настройках сохранённый ключ заполнен в SecureField. Значок глаза позволяет показать его; после сохранения он снова скрыт. На этом шаге автор прямо попросил предоставить уже имеющийся ключ, поэтому локальный личный OpenAI-ключ, ранее использованный для настройки iPhone, явно перенесён в Mac Keychain. Секрет не выводился в чат/логи и не записывался в исходники. Это функциональная настройка по запросу, не диагностическое чтение.

`--provision-connection` читает ConnectionSettings JSON только из stdin и сохраняет через MacKeychainVault без запуска окна/сети. `scripts/provision_mac_connection.py --app /Applications/easytalk.app` берёт локальный источник, передаёт stdin pipe и выводит только статус. У iPhone/extension/Mac по-прежнему разные Keychain и контейнеры; автоматической синхронизации нет. Повторная настройка ключа при запуске Mac теперь не нужна.
