# easytalk

Установлены **iOS 0.5.0 / build26** и **Mac 0.4.1 / build11** (8 октября2026). На Mac выйти ⌘Q и открыть easytalk снова для применения обновления. Ключи и словарь сохранены.

На iPhone убран отвергнутый вариант с открытием easytalk, возвратом в Telegram, предпросмотром и кнопкой вставки. Теперь используем **нижний системный 🎙 iOS** при нашей клавиатуре. Пользователь подтвердил распознавание на лету; перевод/разбор читают текст как набранный. Наше приложение больше не запускает диктовку или переходы. Компиляция/6UIKit прошли. Смешанная речь EN+RU пока не поддержана нашим потоком: русские вставки в английской диктовке распознаются неверно. Язык и системный микрофон остановки управляются iOS. [Состояние и ограничения](docs/SYSTEM_DICTATION_026.md).

Mac: в исправлениях зачёркиваются только изменённые части, примеры можно выделять/копировать. Сценарий отправки: написать в easytalk → поставить курсор в другом приложении → «Перевести и вставить». При недоступном или изменённом поле перевод копируется для ⌘V. Интеграция с чужими полями ещё требует живой проверки. [Описание Mac0.4.1](docs/MACOS_041.md).

Лаборатория локальной оценки произношения сохранена отдельно, по просьбе автора развитие пока отложено. Перевод/грамматика требуют текстового AI API. [Модель и восстановление](docs/LOCAL_VOICE.md); Mac laboratory пока использует runtime/model из проекта, installer не автономный.

Для разработчиков: [HANDOFF](docs/HANDOFF.md), [архитектура](docs/ARCHITECTURE.md), [проверенные архивы](archive/LATEST.md), [восстановление](docs/BACKUP.md). Уроки текущего занятия в памяти, на диске последний разбор; словарь отдельно. Общая коллекция60идиом, пол только в настройках, без автоматических AI-запросов при вводе.

## Структура

- `Sources/EasyTalkCore` — Foundation-контракты, согласование ответов, область перевода, общие идиомы.
- `ios/Shared` / модуль `EasyTalkLearning` на Mac — уроки, слова, предпочтения, карточки и AI-запросы.
- `Sources/EasyTalk` — Mac: NSPanel справа + SwiftUI + NSTextView, меню-бар, хоткей и вставка. Старый NSPanel сохранён для исторического теста.
- `ios/EasyTalk` и `ios/Keyboard` — отдельное приложение и iOS keyboard extension.
- `glossary/idioms-en-ru.json` — редактируемая общая коллекция, генератор `scripts/generate_idioms.py`.
- `prompts/analyze_translate.md` — исходный промпт анализа+перевода.
- `server`, `worker`, `web` — сохранённые серверные/веб-прототипы. Основные native приложения могут использовать личный OpenAI-ключ напрямую.

## Команды

```sh
bash scripts/build.sh all
build/selftest
build/easytalk.app/Contents/MacOS/easytalk --desktop-check build/mac-preview
open build/easytalk.app
python3 scripts/generate_idioms.py --check
bash scripts/test_ios_core.sh
bash scripts/archive.sh next-checkpoint
```

На этом Mac Xcode находится в `~/Downloads/Xcode.app`; при необходимости добавить `env DEVELOPER_DIR=~/Downloads/Xcode.app/Contents/Developer` перед сборкой. На iPhone установлена 0.5.0; Mac 0.4.1 установлен в `/Applications/easytalk.app`. Команды QA не вызывают настоящий AI. Ключ вводится в настройках каждого native клиента и хранится в его Keychain; не включается в архив проекта.

История: CHANGELOG.md, PROCESS.md, DEFERRED.md. Концепты сохранены, но текущие решения выше заменяют старый двухрежимный ввод и popup 0.1.

Для применения Mac 0.4.0 выйти ⌘Q и открыть easytalk; открытый старый процесс при установке не прерывался.
