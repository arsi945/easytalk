# Архитектура easytalk

Состояние на 12 октября 2026 (iOS 0.5.0). Прежнее описание с историей голосовых экспериментов — `docs/history/ARCHITECTURE_v0.5.md`.

## Части

```
 Sources/EasyTalkCore   логика без UIKit: ответ AI и его проверка, InputSnapshot,
                        правила набора, курсор, учебный контент, каталог идиом
 ios/Shared             общее для приложения, клавиатуры и Mac: хранилища,
                        история вводов, контекст для ИИ, AI-запросы, тема
 ios/Keyboard           клавиатура (app extension)
 ios/EasyTalk           приложение: «История и контекст», настройки, примерочное поле
 Sources/EasyTalk       Mac-панель (на паузе, но собирается в CI)
```

Код делится между целями перечислением файлов: `ios/generate_project.py` (iOS-проект), `Package.swift` и `scripts/build.sh` (Mac), `scripts/test_ios_core.sh` (тесты). Новый файл нужно добавить во все нужные списки.

## Хранение

- **App Group** `group.com.easytalk.personal` (в TestFlight-сборке префикс из переменной `BUNDLE_ID_PREFIX`, сейчас `group.com.arsi945.easytalk`). `SharedStorage.defaults()` отдаёт общие `UserDefaults`. Клавиатура пользуется ими только с «Полным доступом», иначе — своим контейнером.
- **Ключ API** — в Keychain, в той же группе (`ConnectionStore`). Приложение пишет, клавиатура читает. В буфер обмена ключ не попадает.
- Ключи `UserDefaults`:
  - `learning.words` — словарь, до 1000;
  - `learning.lessons` — последний разбор;
  - `history.entries` — история, 90 дней, до 3000;
  - `practice.*`, `rewards.*` — карточки и поощрения;
  - `keyboard.*` — настройки.
- **Чтение не теряет данные.** Записи читаются по одной; если часть не читается, исходные байты сохраняются в `<ключ>.unreadable.<время>`.
- При первом запуске каждый процесс один раз копирует свои старые данные в общий контейнер, ничего не перезаписывая (`SharedStorage.migrateLegacyDefaults`).
- Приложение и клавиатура пишут одни ключи. Чтобы не затирать изменения друг друга, клавиатура перечитывает словарь и историю при появлении и перед записью.

## История вводов и контекст

- **`SentTextDetector`** (`ios/Shared/InputHistory.swift`). Клавиатура видит каждое изменение поля. Когда поле опустело, а последняя правка была не нашей клавишей удаления, — сообщение отправлено. Смена поля или чата — не отправка. Кнопку «Отправить» хост-приложения клавиатура не видит, поэтому это единственный сигнал.
- **`InputHistoryStore`**: запись = время + текст, а для текста из «Перевести» — ещё исходник и исправленный английский. Повтор того же текста в течение 10 минут не дублируется.
- **`ContextExport`**: задание из `prompts/context_export.md` и пронумерованные сообщения за период. Предел — 60 000 символов, при переполнении остаются самые новые.
- **`WordImport`** читает блок `EASYTALK-WORDS … END-EASYTALK-WORDS` из ответа ИИ, терпимо к разметке чатов. `LearningStore.importWords` добавляет слова без дублей.

## «Перевести»

1. Берётся выделение или текущий абзац (`InputSnapshot`), не больше 2000 символов.
2. `AnalysisService.makeRequest` строит запрос к выбранному провайдеру. Один повтор «repair» — если ответ не прошёл проверку.
   - После PR #8 есть два формата: OpenAI-совместимый (OpenAI, Qwen, DeepSeek) и Anthropic Messages API (Claude).
   - Ключ отправляется только на хосты провайдера.
3. Ответ проверяется локально (`LearningResponse.normalized`). Смещения пересчитываются по тексту, применённые правки обязаны точно дать `corrected`. Отказ модели или обрезанный ответ — ошибка, текст в поле не трогается.
4. Перед заменой поле сравнивается со снимком; поздний ответ отбрасывается по счётчику поколения. Курсор сдвигается к концу абзаца в единицах UTF-16, абзац удаляется и вставляется перевод.

## Клавиатура

`KeyboardViewController` (~1700 строк) пока делает всё сам: раскладку, ввод, трекпад пробела, панели «Учёба», «Контекст», «Настройки», игру и AI-запросы. Разделение — этап 6 плана.

- **Правила набора** — `TypingRules` в Core: автозаглавная, точка по двойному пробелу, удаление по словам.
- **Клавиши** — `KeyboardKey`: срабатывают на касание. Долгое нажатие даёт второй символ (ь→ъ, е→ё). Звук и вибрация — через общий обработчик.
- **Диктовка** — системная (`hasDictationKey = false` оставляет нижнюю кнопку 🎙 iOS).

## Сборка

- **CI** (`.github/workflows/ci.yml`, `macos-26`, Xcode 26): тесты логики, сверка проекта с генератором, Mac-сборка + QA, iOS-сборки без подписи.
- **TestFlight** (`testflight.yml`): архив с автоматической облачной подписью через ключ App Store Connect, номер сборки = 26 + номер запуска. См. `docs/CI.md`.
