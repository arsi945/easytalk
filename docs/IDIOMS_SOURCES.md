# Общая коллекция идиом · 2026-10-06

Встроенная коллекция увеличена с 12 до 60 выражений. Она работает без сети на iPhone и Mac. Это учебная подборка, а не словарь всех идиом и не рейтинг частотности.

## Источники и подготовка

Для выбора повседневных выражений просмотрены реальные коллекции:

- [EF: English idioms](https://www.ef.com/wwen/english-resources/english-idioms/).
- [British Council: Top 20 English idioms](https://takeielts.britishcouncil.org/blog/top-20-english-idioms-to-be-more-fluent-in-ielts-speaking).
- [Wiktionary](https://en.wiktionary.org): отдельные статьи для проверки значения каждого нового выражения, кроме Hang in there, сверенного по EF.

Ссылки на конкретные статьи и дата проверки находятся в поле `source` / `verified` каждой записи в `glossary/idioms-en-ru.json`. Источник показывается рядом с идиомой в macOS. Русские смыслы, замечания и новые примеры подготовлены для easytalk; длинные цитаты, примеры издательств и готовые платные базы не импортировались. Первые 12 записей происходят из предоставленного автором `second-skill.zip`; их ID `second-skill.i1…i12` сохранены. В одном старом примере исправлена конструкция с morning walk.

Учебные темы: общение, работа, чувства, трудности, решения, время и деньги. Значение зависит от контекста: буквальные переводы в качестве основного смысла не используются. Выражения сохраняются без обязательного `to`: например, learn the ropes — нормальная словарная форма глагольного выражения. В предложении форма меняется по грамматике.

## Один источник для двух платформ

Редактировать JSON, затем выполнить:

```sh
python3 scripts/generate_idioms.py
python3 scripts/generate_idioms.py --check
python3 ios/generate_project.py
```

Генератор проверяет уникальность выражений и ID, заполненность полей, отсутствие `pending`, сохранность первых 12 ID. `Sources/EasyTalkCore/IdiomCatalog.swift` генерируется для сборки без чтения ресурсов во время запуска. `ios/Shared/SecondSkillCards.swift` преобразует его в игровые карточки; Mac использует ту же коллекцию. Игра остаётся раундом из 4 карточек, сохранённые слова идут первыми. Пополнение базы не сбрасывает отметки «выучено».

## Следующий этап

Редакторская вычитка живым преподавателем, транскрипция/произношение, поиск по темам на iPhone и интервальные повторения. Сейчас нет заявленных уровней CEFR или статистики употребления. Публичную публикацию исходных 12 записей согласовать с автором предоставленного архива; локальная сборка использует его материал по запросу.
