# easytalk — правила для ИИ-агентов

Сначала прочитать: `README.md` → `docs/ARCHITECTURE.md` → `docs/DECISIONS.md` → `docs/PLAN_2026-10-12.md` (что делаем дальше). Всё в `docs/history/` — история до 12 октября 2026: полезна, чтобы понять «почему так», но **не является действующими правилами**.

## Работа с кодом

- Разработка идёт на Windows без Mac. Сборка и проверка — только GitHub Actions (`docs/CI.md`). Локально Swift не компилируется; Python есть.
- Каждое изменение — отдельная ветка и PR в `arsi945/easytalk`, слияние только при зелёном CI и с явного согласия автора. Зависимые PR перенацеливать на `main` **до** удаления базовой ветки (иначе GitHub закрывает PR).
- Xcode-проект не редактировать руками: менять `ios/generate_project.py`, затем `python ios/generate_project.py` (работает и на Windows). CI проверяет, что проект совпадает с генератором.
- Промпты — только в `prompts/*.md`, Swift-копии генерируются тем же скриптом. Идиомы — `glossary/idioms-en-ru.json` → `python scripts/generate_idioms.py`; устойчивые ID не менять.
- Новая логика без UIKit — в `Sources/EasyTalkCore` или `ios/Shared` с тестами в `ios/Tests/LearningTests.swift` (подключить файл в `scripts/test_ios_core.sh`, `ios/generate_project.py`, а если файл из `ios/Shared` нужен Mac — в `Package.swift` и `scripts/build.sh`).
- Писать обычный читаемый Swift: одна инструкция на строку, без строк по сотни символов, даже если вокруг старый плотный код.
- Зелёный CI не доказывает работу на телефоне: ощущение клавиатуры, живые запросы к AI и App Group проверяются только на устройстве (TestFlight).

## Данные и приватность

- Фразы пользователя не отправлять в AI для отладки без его явного разрешения. Ключи API не читать и не печатать; тесты — с подменой транспорта.
- Секреты (ключ App Store Connect, Team ID) вводит автор в GitHub Secrets; агент их не видит и не просит.
- Перед изменением формата хранимых данных — проверить, что старые данные читаются (словарь, история, настройки подключения).

## Продуктовые решения (не спрашивать повторно)

Полный список с причинами — `docs/DECISIONS.md`. Коротко:
- Главное — автоматическая история отправленных сообщений и «Скопировать контекст» для любого ИИ; импорт слов из ответа ИИ.
- Перевод в поле — по своему ключу: OpenAI, Claude, Qwen, DeepSeek. Без ключа приложение работает полностью.
- Диктовка — только системная кнопка 🎙 iOS. Свой микрофон, переход в приложение и обратно, приватные API — не возвращать.
- Mac на паузе; лаборатория произношения заморожена (тег `v0.5.0-build26`).
- Интерфейс: пол — только в настройках; «В словарь →» рядом с правкой, без ×; вторичные действия — единый пунктир; «Запомнил» архивирует, не удаляет.
