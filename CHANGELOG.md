# Изменения

С 11 октября 2026 — по PR в `arsi945/easytalk`, новые сверху. Раньше — `docs/history/CHANGELOG_2026-09-30_to_10-08.md`.

## 2026-10-15

- **Исправление** (PR #8): «Перевести» читает всё сообщение, даже когда iOS показывает клавиатуре только кусок (Telegram обрезает на предложении или запятой): курсор проходит поле и возвращается на место. EN/RU возвращает буквы из цифр и символов.

## 2026-10-14

- **Настройки** (PR #7): новый экран настроек с разделами; мастер подключения AI в 4 шага с «Открыть сайт» и автопроверкой, карточка подключения; экран «Как пользоваться»; статус клавиатуры и «Полного доступа».
- **Клавиатура** (PR #6): «Перевести» по умолчанию переводит всё сообщение, настройка «Что переводить»; «В словарь» для выделенного слова или фразы, без ключа — «без перевода» до «Вставить слова»; советы о клавиатуре по одному.
- **Подсказки слов** (PR #5): ряд из трёх подсказок над клавишами — замена текста iOS, свои слова из истории, исправления и дополнения; без автозамены; по умолчанию выключен.

## 2026-10-12

- **Этап 5** (PR #8): свой ключ API — OpenAI, Claude, Qwen, DeepSeek; два формата запроса; ключ только на хосты провайдера; режим «свой сервер» удалён. Сборка 33 в TestFlight.
- **Исправление** (PR #9): «Перевести» с курсором в середине абзаца удаляла не тот текст после эмодзи — сдвиг курсора теперь в UTF-16.
- **Этап 4** (PR #7): ё на долгом е, автозаглавная, Caps Lock, точка по двойному пробелу, удаление по словам, звук и вибрация, подпись Enter по полю, цифры в цифровых полях, запоминание EN/RU, кнопка «Свернуть клавиатуру». Сборка 32.
- **CI на Xcode 26** (PR #6): App Store Connect требует iOS 26 SDK. Первая загрузка в TestFlight — сборка 31.
- **Этап 3** (PR #4, #5): «Скопировать контекст» и «Вставить слова» в приложении и клавиатуре; экран «История и контекст»; словарь до 1000 слов.
- **Этап 2** (PR #3): автоматическая история отправленных сообщений, 90 дней.
- **Этап 1** (PR #2): App Group для приложения и клавиатуры, ключ API в общем Keychain вместо буфера обмена, словарь не теряется при ошибке чтения.

## 2026-10-11

- **Этап 0** (PR #1): удалены голосовые эксперименты, виджет, лаборатория произношения с ONNX Runtime, старая Mac-панель и контракт `correct`; генератор проекта падает на отсутствующем файле.
- Git, приватный репозиторий, CI и workflow TestFlight; иконка; генератор работает на Windows.
- Тег `v0.5.0-build26` — исходное состояние комплекта (iOS 0.5.0/26, Mac 0.4.1/11).
